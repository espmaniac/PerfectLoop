# Unified preview

The main viewer has two comparison choices: Original and Result. Original plays the selected source range with the current video framing, excluding loop effects and layers. Its output proportions and crop coordinates match Result. Result automatically generates one complete processed cycle after a 900 ms pause in editing. The output is reduced in resolution for preview, never capped to a five- or six-second sample. New videos and Reset use the full source duration. Sources outside Spotify's 3–8 second range open with Custom settings rather than silently trimming the source.

Changing settings immediately leaves stale encoded output and shows a clearly labeled draft while updating. Result displays the processed duration and selected source duration; dissolves explain overlap shortening. A failed or cancelled revision does not retry automatically. Retry result is available, and a new edit schedules a new attempt.

Find keeps source-range playback so users can search the full video. Choosing a candidate applies its range, compares methods, and then generates the chosen result. Layers keeps live composition editing for transforms; leaving Layers updates the processed result. These are editing contexts, not additional user-facing playback modes. Original suspends automatic rendering. Video move, scale, and rotate gestures stay in Original until Result is explicitly selected. Returning from Result restores the editor camera for the same source and selection, retaining zoom and frame placement. A new source, selection, or stage size refits the view.

Rendering uses the existing cancellable engine and job controls. Controls remain disabled while encoding; this does not introduce background parallel encoding. Rapid edits are coalesced, and active transform gestures postpone encoding. Export settings and duration rules are unchanged.
