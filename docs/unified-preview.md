# Unified preview

The main viewer has two comparison choices: Original and Result. Original plays the selected source range with the current video framing, excluding loop effects and layers. Its output proportions and crop coordinates match Result. Play in Result generates one complete processed cycle when needed, then starts playback. An unchanged result plays immediately. The output is reduced in resolution for preview, never capped to a five- or six-second sample. New videos and Reset use the full source duration. Sources outside Spotify's 3–8 second range open with Custom settings rather than silently trimming the source.

Changing settings pauses Original or Result, leaves stale encoded output, and shows a clearly labeled draft. Edits, loading media, changing comparison choices, and leaving Layers never start a render. Result displays the processed duration and selected source duration; dissolves explain overlap shortening. A failed or cancelled render stays paused; Play retries explicitly. The Play button indicates when it will update Result and shows a busy state while encoding. There is no separate header update or retry button.

Find keeps source-range playback so users can search the full video. Choosing a candidate applies its range and compares methods; Play generates the chosen result. Layers keeps live composition editing for transforms; Play in Result checks the encoded cycle there too. These are editing contexts, not additional user-facing playback modes. Video move, scale, and rotate gestures stay in Original until Result is explicitly selected. Returning from Result restores the editor camera for the same source and selection, retaining zoom and frame placement. A new source, selection, or stage size refits the view.

Rendering uses the existing cancellable engine and job controls. Controls remain disabled while encoding; repeated Play requests share the pending request. Cancellation invalidates pending autoplay, and a changed source or result cannot resume an outdated playback request. Explicit repair analysis and repair preview actions still render when requested. Wallpaper layout views remain static; choose Video and press Play in Result to update the rendered key photo. Export settings and duration rules are unchanged.
