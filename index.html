What to look for

Check the direction and speed of motion at the join. A matching still frame can hide a change in velocity. Bright areas in the difference map show change, including normal motion.

Ping-pong reverses direction; dissolves can show ghosting. A rendered preview uses the export's loop logic at a smaller resolution. Check the downloaded file at full size too.

Make a better loop

Open a video, select a range, choose a method, then render the loop preview. Watch it repeat before exporting.

  • Auto find compares color, local image structure, and movement. The best five matches receive frame refinement. Sampling can miss very brief moments.
  • Crossfade overlaps the tail and head; the output is shorter than the selection. Offset dissolve places that transition inside the clip.
  • Ping-pong plays forward, then backward, nearly doubling the cycle duration without repeating turning-point frames. Smooth ping-pong slows down into the turns. GIF stores both directions in one cycle; Loop forever repeats that cycle.
  • Remove audio track strips the audio stream. Muting the player only changes the preview.
  • Spotify Canvas uses 3–8 seconds, exact 9:16, and 720–1080px height. The default 576×1024 is inside these limits.
  • Long videos are sampled from the local file. Unsupported browser codecs can be converted to a playable proxy.
